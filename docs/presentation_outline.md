# Presentation Outline

1. Problem and goal: safe and convenient companion search for intercity and suburban rides
2. Architecture: 9 microservices plus React dashboard
3. Mandatory modules walkthrough: trips, search, booking/payment, ratings, verification, chat
4. Optional improvements: dynamic pricing, recommendations, caching, async payments, tracker, emergency
5. Quality metrics and targets: search `<2s`, booking `<5s`, `100000` trips/day strategy
6. Demo: booking workflow, cancellation with refund, emergency workflow
7. Testing and reliability: unit, integration, and load stubs
8. Result and next steps: production hardening, mobile app, provider integrations
